# docs/

This is the team's shared space for ideas, notes and planning documents. **If you have an idea, a suggestion or a draft, put it here, not in the code.** The code is changed only through a pull request on a feature branch (see [../CONTRIBUTING.md](../CONTRIBUTING.md)).

## How to add a document

1. Create a Markdown file (`.md`) in the right sub-folder.
2. Name it `YYYY-MM-DD_your-name_topic.md`, for example `2026-11-05_ali_dashboard-idea.md`.
3. Start the file with a short title and who wrote it. Use plain headings and bullet points.
4. Commit it on a `docs/<short-name>` branch, or ask the group leader to add it.
5. Do not edit someone else's document. Add a comment in your own file and link to theirs.

## Folders

| Folder | Put here |
|---|---|
| `ideas/` | Feature ideas, suggestions, improvements |
| `requirements/` | Requirement changes and clarifications (FR/NFR) |
| `design/` | Wireframes, screen flows, colour scheme, diagrams (images and exported PDFs welcome) |
| `meetings/` | Short meeting notes: date, who attended, decisions, next steps |
| `research/` | Notes from reading: SDG 13.3, emission factors, PDPA, similar apps |

## Rules

- No passwords, API keys, phone numbers or personal data of survey respondents.
- Keep each document short and specific. One idea per file.
- If an idea is accepted, the owner turns it into a requirement or task in `TASKS.md` through a pull request.
