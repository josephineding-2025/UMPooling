# evidence/

Proof for the report, video and peer evaluation. Remove names, phone numbers, emails and matric numbers of other people before committing.

| Put here | Examples |
|---|---|
| Survey | Exported responses (no email column), charts, analysis summary |
| UM unit contact | Screenshot of the sent email, the reply, permission to quote |
| User tests | Task timings, SUS scores, quotes |
| Test results | NFR measurements, load test output, AI evaluation tables |
| Screenshots | App screens used in the report and video |

Suggested sub-folders: `survey/`, `um-unit/`, `user-tests/`, `test-results/`, `screenshots/`.
